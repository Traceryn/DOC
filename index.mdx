Traceryn is an open-source organization that builds practical, developer-first tools and libraries. Our goal is to simplify everyday workflows, improve performance, and make development more enjoyable.

<Info>
  **Traceryn is not limited to the projects listed here.** TikTok SDK and Pinto are our first published libraries. New tools are in active development, and each one gets its own tab in these docs when it ships.
</Info>

## How these docs are organized

<Steps>
  <Step title="Pick a project from the top tabs">
    Every Traceryn project has its own tab at the top of the page. The **Home** tab (this one) covers the organization as a whole.
  </Step>
  <Step title="Start with Get started">
    Inside each project tab, the **Get started** group explains what the project does and how to install it.
  </Step>
  <Step title="Go deeper with guides and reference">
    Guides walk through real tasks such as sessions, proxies, and deployment. The reference pages list every available method.
  </Step>
</Steps>
