---
title: "Traceryn"
description: "Lightweight, fast, developer-first open-source tooling for tracing and structuring data across the web."
---

Traceryn builds practical developer tools and libraries designed to simplify workflows, improve performance, and make development more enjoyable.

Every project is open source, written in TypeScript, and published under the MIT License.

## Projects

<CardGroup cols={2}>
  <Card title="TikTok SDK" icon="video" href="/tiktok-sdk/overview">
    Unofficial TikTok API wrapper for Node.js. Fetch videos, users, comments, playlists, hashtags, and sounds.
  </Card>

  <Card title="Pinto" icon="thumbtack" href="/pinto/overview">
    Headless TypeScript/JavaScript API for Pinterest Web. Read pins, boards, profiles, and search results.
  </Card>
</CardGroup>
