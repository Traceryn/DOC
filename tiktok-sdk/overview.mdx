`@traceryn/tiktok-sdk` is a lightweight TikTok SDK for Node.js. It fetches videos, users, comments, playlists, hashtags, sounds, and search data and returns them in a clean, structured shape.

## How it works

- The SDK talks to TikTok through web endpoints and structured responses.
- [Playwright](/tiktok-sdk/playwright-sessions) is optional. It only helps when a browser-backed session makes sense.
- This keeps setup light for normal use, so you don't need a full browser to start.
- Every call passes through a request pipeline (cache, queue, rate limiter, circuit breaker, proxy rotation, and retries). A multi-strategy **ParserEngine** then extracts TikTok's embedded page data, and **X-Bogus** signing handles TikTok's web API.
