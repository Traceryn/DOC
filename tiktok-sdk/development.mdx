Clone the repository and install dependencies:

```bash
git clone https://github.com/Traceryn/tiktok-sdk.git
cd tiktok-sdk
npm install
```

## Run checks

```bash
npm test          # Vitest suite
npm run typecheck # TypeScript type check
npm run lint      # Type check and ESLint
```

Most tests are local, but some checks depend on TikTok behavior and can shift when the site changes. If you're only testing one area, run the smallest check that covers your change.

## Run the examples

```bash
npm run example
```
