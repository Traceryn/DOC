Pinto is an unofficial TypeScript/JavaScript API for reading public Pinterest data: pins, boards, profiles, and search results.

<Warning>
  **Status: pre-release.** Pinto is under active development and the public API may still change before `1.0.0`. The read surface (`getPin`, `getUser`, `getBoard`, `search`, media downloads) is stable and covered by a live test suite. Pin your version in production.
</Warning>

## Why Pinto

<CardGroup cols={2}>
  <Card title="No browser required" icon="bolt">
    Pinto talks to Pinterest's public widget and resource endpoints directly over `fetch`. No Selenium, no Puppeteer, no Chromium.
  </Card>

  <Card title="Read-only by design" icon="eye">
    It fetches public pins, boards, profiles, and search results. It never posts, follows, or messages on your behalf.
  </Card>

  <Card title="Anonymous out of the box" icon="user-secret">
    Each session gets a stable, randomly selected browser profile so every client reads as a distinct device. See [Device fingerprinting](/pinto/fingerprinting).
  </Card>

  <Card title="Built to scale" icon="server">
    A session pool, shared cache, global rate limiter, and coalescing gateway. See [Scaling](/pinto/scaling).
  </Card>
</CardGroup>

Pinto has a fully typed public surface and ships both ESM and CJS builds.
